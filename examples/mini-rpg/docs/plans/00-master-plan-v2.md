# Mini RPG 총괄 계획서 v2

## 1. 프로젝트 개요

**비전**: 마인크래프트 스타일 오픈월드 탐험과 클래식 영웅담 스토리가 결합된 2D 탑다운 RPG. 메인 스토리 완료 후에도 계속 플레이 가능한 열린 세계.

**핵심 게임플레이**:
- 여러 지역(마을 2~3개, 필드, 던전)이 연결된 오픈월드 자유 탐험
- 메인 스토리: 마을을 위협하는 악의 세력을 물리치는 용사의 여정
- 다양한 사이드 퀘스트로 세계관 확장
- 장비/스킬 기반 전투 성장 시스템
- 엔드게임: 스토리 클리어 후에도 탐험, 파밍, 도전 콘텐츠 지속

**기술 스택**: you-engine (ES6 모듈), Canvas 2D API, JSON 데이터 기반

**현재 상태**: 기본 전투, 인벤토리/장비 시스템 완료

## 2. Phase 로드맵

### Phase 2: 전투 확장
- 투사체 시스템 (원거리 공격 실제 구현)
- 스킬 시스템 (액티브 스킬 2~3개)
- 보스 몬스터 (패턴 기반 AI)

### Phase 3: 맵/지역 시스템
- 타일맵 기반 지형
- 지역 전환 (포탈/출입구)
- 지역별 몬스터 테이블

### Phase 4: NPC/대화 시스템
- NPC 오브젝트 및 상호작용
- 대화 UI (텍스트 박스)
- 상점 시스템

### Phase 5: 퀘스트 시스템
- 퀘스트 데이터 구조
- 퀘스트 추적 UI
- 메인/사이드 퀘스트

### Phase 6: 콘텐츠 & 엔드게임
- 스토리 콘텐츠 (메인 퀘스트 라인)
- 던전 설계
- 엔드게임 콘텐츠
