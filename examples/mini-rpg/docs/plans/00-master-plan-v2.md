# Mini RPG 총괄 계획서 v2

## 1. 프로젝트 개요

**비전**: 마인크래프트 스타일 오픈월드 탐험과 클래식 영웅담 스토리가 결합된 2D 탑다운 RPG. 메인 스토리 완료 후에도 계속 플레이 가능한 열린 세계.

**핵심 게임플레이**:
- 여러 지역(마을 2~3개, 필드, 던전)이 연결된 오픈월드 자유 탐험
- 메인 스토리: 마을을 위협하는 악의 세력을 물리치는 용사의 여정
- 다양한 사이드 퀘스트로 세계관 확장
- 장비/스킬 기반 전투 성장 시스템
- 엔드게임: 스토리 클리어 후에도 탐험, 파밍, 도전 콘텐츠 지속

**기술 스택**: you-engine (ES6 모듈), Canvas 2D API, JSON 데이터 기반

**현재 상태**: 기본 전투, 인벤토리/장비 시스템 완료

## 3. Phase 2 상세: 전투 확장

### 3.1 투사체 시스템

**Projectile 오브젝트**:
- 속성: 위치, 방향, 속도, 데미지, 소유자, 관통 여부
- 무기 속성에 따라 동작 결정:
  - 화살: 단일 타격 후 제거
  - 마법: 관통 (횟수 제한)
- 사거리 초과 또는 최대 충돌 횟수 도달 시 제거

**구현 요소**:
- `Projectile` 오브젝트 + `ProjectileBehavior` 컴포넌트
- `ProjectileManager` 서비스 (충돌 검사, 생성/제거 관리)

### 3.2 스킬 시스템

**스킬 슬롯 + 장비 연동**:
- 스킬 슬롯 3개 (Q, W, E 키)
- 장착 무기에 따라 사용 가능한 스킬 풀 결정
- 플레이어가 슬롯에 원하는 스킬 배치

**스킬 데이터 구조**:
- `id`, `name`, `description`
- `cooldown`, `manaCost` (또는 자원 소모)
- `effectType`: projectile, aoe, buff, dash 등
- `weaponTypes`: 사용 가능한 무기 타입 목록

**초기 스킬 예시**:
- 대시 (모든 무기): 짧은 거리 순간 이동
- 회전베기 (근접 무기): 주변 적에게 범위 데미지
- 다중 발사 (원거리 무기): 부채꼴로 3발 발사

### 3.3 보스 시스템

**페이즈 기반 패턴**:
- HP 구간별 페이즈 전환 (예: 100~70%, 70~40%, 40~0%)
- 각 페이즈마다 패턴 풀에서 랜덤 선택
- 페이즈 전환 시 연출 (잠시 무적, 이펙트 등)

**패턴 예시**:
- 돌진: 플레이어 방향으로 빠르게 이동
- 범위 공격: 일정 범위에 데미지
- 소환: 일반 몬스터 소환
- 연속 발사: 여러 투사체 발사

**구현 요소**:
- `BossAI` 컴포넌트 (EnemyAI 확장)
- 보스 데이터 JSON (페이즈별 패턴 풀 정의)

## 4. Phase 3 상세: 맵/지역 시스템

### 4.1 타일맵 시스템

**Tiled 맵 에디터 호환**:
- `.tmj` (Tiled JSON) 파일 형식 지원
- 레이어 구조: 바닥, 장식, 충돌, 오브젝트
- 타일셋 이미지 로딩 및 렌더링

**TileMap 구현**:
- `TileMap` 클래스: 맵 데이터 파싱, 타일 렌더링
- `TileMapRenderer` 컴포넌트: 레이어별 렌더링
- 충돌 레이어 기반 이동 제한

### 4.2 지역 전환 시스템

**이중 전환 방식**:
- 포탈/출입구: 던전 입구, 건물 문 등 특정 오브젝트
- 맵 경계: 필드 간 이동 시 경계에 도달하면 자동 전환

**전환 데이터**:
- `Portal` 오브젝트: targetMap, targetPosition
- 맵 경계 연결 정보: 북/남/동/서 인접 맵 ID

**전환 처리**:
- 페이드 아웃 → 맵 로드 → 플레이어 배치 → 페이드 인
- `MapManager` 서비스: 맵 로딩, 전환 관리

### 4.3 지역별 몬스터 테이블

**스폰 시스템**:
- 지역별 몬스터 테이블 JSON
- 스폰 포인트 (Tiled 오브젝트 레이어에서 정의)
- 최대 몬스터 수, 리스폰 간격

**데이터 구조**:
```json
{
  "regionId": "forest_east",
  "monsters": [
    { "type": "mushroom", "weight": 5 },
    { "type": "ant", "weight": 3 }
  ],
  "maxCount": 10,
  "respawnInterval": 5
}
```

## 5. Phase 4 상세: NPC/대화 시스템

### 5.1 NPC 오브젝트

**NPC 구조**:
- `NPC` 오브젝트 + `NPCBehavior` 컴포넌트
- 속성: id, name, dialogueId, shopId (상점 NPC인 경우)
- Tiled 오브젝트 레이어에서 배치

**상호작용**:
- 플레이어 접근 시 말풍선 아이콘 표시 ("!" 또는 "...")
- E키로 대화 시작
- 상호작용 범위: 약 50px

### 5.2 대화 시스템

**대화 UI**:
- 화면 하단 텍스트 박스
- NPC 이름, 대화 내용 표시
- 스페이스/E키로 다음 대화, ESC로 종료

**대화 데이터 구조**:
```json
{
  "dialogueId": "elder_intro",
  "lines": [
    { "speaker": "촌장", "text": "어서 오게, 젊은 용사여." },
    { "speaker": "촌장", "text": "우리 마을에 큰 위협이 닥쳤다네..." }
  ],
  "onComplete": { "action": "startQuest", "questId": "main_01" }
}
```

**분기 대화** (선택지):
- `choices` 배열로 선택지 제공
- 선택에 따라 다른 dialogueId로 이동

### 5.3 상점 시스템

**화폐**:
- 골드 단일 화폐
- 몬스터 드롭, 퀘스트 보상으로 획득

**상점 UI**:
- 구매/판매 탭
- 아이템 목록, 가격 표시
- 플레이어 소지 골드 표시

**상점 데이터**:
```json
{
  "shopId": "village_weapon",
  "name": "무기 상점",
  "items": [
    { "itemId": "sword_iron", "price": 100 },
    { "itemId": "bow_wood", "price": 80 }
  ]
}
```

**구현 요소**:
- `ShopUI` 클래스
- 플레이어 골드: `Stats` 또는 별도 `Wallet` 컴포넌트

## 6. Phase 5 상세: 퀘스트 시스템

### 6.1 퀘스트 데이터 구조

**퀘스트 타입**:
- `kill`: 특정 몬스터 N마리 처치
- `collect`: 특정 아이템 N개 수집
- `talk`: 특정 NPC와 대화

**퀘스트 데이터**:
```json
{
  "questId": "main_01",
  "type": "main",
  "name": "마을의 위협",
  "description": "숲에 출몰하는 버섯 몬스터를 처치하라.",
  "objectives": [
    { "type": "kill", "target": "mushroom", "count": 5, "current": 0 }
  ],
  "rewards": {
    "exp": 100,
    "gold": 50,
    "items": [{ "itemId": "potion_medium", "count": 3 }]
  },
  "prerequisite": null,
  "nextQuest": "main_02"
}
```

### 6.2 퀘스트 관리

**QuestManager 서비스**:
- 활성 퀘스트 목록 관리
- 진행 상황 추적 (이벤트 기반)
- 완료 조건 체크 및 보상 지급

**이벤트 연동**:
- 몬스터 처치 → `kill` 목표 업데이트
- 아이템 획득 → `collect` 목표 업데이트
- NPC 대화 완료 → `talk` 목표 업데이트

### 6.3 퀘스트 UI

**퀘스트 추적 UI**:
- 화면 우측에 현재 퀘스트 목표 표시
- 진행 상황 (예: "버섯 처치 3/5")

**퀘스트 로그**:
- J키로 퀘스트 목록 열기
- 메인/사이드 퀘스트 탭 구분
- 퀘스트 상세 정보, 보상 미리보기

### 6.4 메인/사이드 퀘스트

**메인 퀘스트**:
- 스토리 진행에 필수
- 선형 구조 (prerequisite로 연결)
- 완료 시 다음 퀘스트 자동 시작

**사이드 퀘스트**:
- 선택적 수행
- NPC 대화로 수락
- 추가 보상 (골드, 아이템, 경험치)

## 7. Phase 6 상세: 콘텐츠 & 엔드게임

### 7.1 월드 구성

**지역 구성**:
- 시작 마을 (평화로운 마을)
- 동쪽 숲 (초반 사냥터)
- 서쪽 평원 (중반 사냥터)
- 북쪽 산악 (고레벨 지역)
- 어둠의 성 (최종 던전)
- 숨겨진 동굴 (엔드게임 던전)

**던전 구조**:
- 여러 층으로 구성
- 각 층마다 몬스터 + 보물상자
- 최종 층에 보스

### 7.2 메인 스토리 개요

**스토리 라인**:
1. 촌장에게 마을 위협 소식 듣기
2. 동쪽 숲 몬스터 소탕
3. 서쪽 평원에서 단서 발견
4. 북쪽 산악에서 악의 근원 추적
5. 어둠의 성 진입, 최종 보스 처치
6. 마을에 평화 귀환

**예상 메인 퀘스트**: 8~10개

### 7.3 엔드게임 콘텐츠

**파밍 콘텐츠**:
- 숨겨진 동굴: 희귀 장비 드롭
- 고레벨 몬스터: 강화 재료 드롭
- 일일 보스: 매일 리셋되는 특별 보스

**도전 콘텐츠**:
- 타임어택: 던전 클리어 시간 기록
- 무한 던전: 층을 올라갈수록 강해지는 몬스터, 최고 기록 도전
- 하드모드 보스: 강화된 패턴의 보스 재도전

### 7.4 밸런스 가이드라인

**레벨 구간**:
- Lv 1~5: 시작 마을, 동쪽 숲
- Lv 5~10: 서쪽 평원
- Lv 10~15: 북쪽 산악
- Lv 15~20: 어둠의 성
- Lv 20+: 엔드게임 콘텐츠

**장비 티어**:
- 일반 (흰색)
- 고급 (녹색)
- 희귀 (파란색)
- 전설 (보라색) - 엔드게임 전용
